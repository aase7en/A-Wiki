# /A-2.5DAnimation — 2.5D animated backgrounds แบบ luxury

Maps to: `skills/awiki/a-2-5d-animation/SKILL.md`

## When to use
- สร้าง/รีวิว 2.5D animated background (moving clouds, water, foliage) จาก locked master scene
- LED signage / environmental widget scenes ที่ต้อง independent-layer motion
- เลือก visual style แบบ image-first A/B/C/D ก่อน render
- ตรวจ crop-safe API overlay + readability ของ scene

Auto-picks on: `2.5d animation`, `luxury led`, `layered scenic video`, `moving clouds water foliage`

## Flow
1. Entry gate: ถ้า art direction ยังไม่ clear → ใช้ `grill-with-docs` (หรือ GrillMe plugin ใน ChatGPT) ถามแบบ bounded ทีละข้อ
2. Style selection: A/B/C/D image-backed choices — ใช้ approval เดิมถ้ามี, อย่าถามซ้ำ
3. Master composition ความละเอียดสูงตาม aspect จริง (ไม่ scale รูปสี่เหลี่ยมจัตุรัส)
4. Independent layers: sky นิ่ง, clouds far/near เลื่อนคนละความเร็ว, wrap ต่อเนื่องไม่ snap
5. Export: iPhone-compatible MP4 + GIF, full-width + target-display proofs, travel-aware duration
6. ตรวจ motion จริงบนอุปกรณ์ + owner visual sign-off ก่อนถือว่าสำเร็จ (จำนวนรูปที่ generate ไม่ใช่พิสูจน์ motion)
