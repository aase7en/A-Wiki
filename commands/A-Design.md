# /A-Design — งาน UX/UI design มืออาชีพ

Maps to: `skills/awiki/a-design/SKILL.md`

## When to use
- ออกแบบ UI ใหม่ (web/mobile/dashboard) ตั้งแต่ต้น
- ทำ design system / token architecture
- Review UI ว่า "ดู AI-generated ไหม" (Distinctiveness gate)
- เลือก palette/font/style ตามประเภท product
- วาง motion/animation ที่ production-safe

Auto-picks on: `ออกแบบ UX`, `design system`, `wireframe`, `visual hierarchy`, `UI สวย`

## Flow
1. focus_set
2. Composition decision: pick grammar × recipe × adapter × profile (4-axis)
3. Resolve conflict by authority order (a11y > grammar > adapter > recipe > profile)
4. Quality Gate 8-category rubric — must score ≥80/100 to ship
5. focus_clear

## Key bound skills
- `ui-ux-pro-max` (161 palettes, 74 fonts, 99 rules, 22 stacks) — data layer
- `taste-skill` (anti-AI-slop: Lila Rule, Premium-Consumer Ban, Serif Discipline) — methodology
- `transitions-dev` (21 CSS transitions, reduced-motion) — motion
- `motion-foundations/patterns/advanced` — React motion system
- `accessibility` (WCAG 2.2 AA, cross-platform) — a11y from start
