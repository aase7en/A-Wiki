# SCT-013-000 (Non-Invasive AC Current Sensor)

**ผู้ผลิต**: SCT-013 series (YHDC ต้นฉบับ / clone จีน)
**รุ่น**: SCT-013-000 (100A / 50mA)
**สถานะใน Lab**: ❌ ยังไม่มี — ต้องซื้อ
**ราคาประมาณ**: ~200 บาท ⚠️ **VERIFY ก่อนสั่งซื้อ** (Scout 2026-07-24: ร้านไทยดึงราคา live ไม่ได้ ต้องเปิด Shopee/Lazada ด้วยมือ — environment นี้ไม่มี headless browser ที่จะ render JS-only catalog pages)

## ภาพรวม

SCT-013-000 เป็น **split-core current transformer (CT) clamp** วัดกระแส AC แบบ **non-invasive** — ไม่ต้องตัดสายไฟ แค่รัด "jaws" ล้อมสาย live wire ตัวเดียว เหมาะมากสำหรับมอนิเตอร์การใช้ไฟของอุปกรณ์ที่ติดตั้งอยู่แล้ว (แอร์, ปั๊ม, ตู้แช่) ในสถานที่จริงเช่น <HOSPITAL>

## Specs หลัก

| พารามิเตอร์ | ค่า | หมายเหตุ |
|------------|------|---------|
| Input Current (primary) | 0–100A AC | เพียงพอสำหรับแอร์ residential/small commercial |
| Output Current (secondary) | 0–50mA | ต้องใช้ burden resistor แปลงเป็น voltage |
| Aperture (รูเสียบสาย) | 13mm Ø | รองรับสายไฟตัวเดียว (ไม่ใช่สาย 3 สายรวมกัน) |
| Accuracy | ±1% (typical) | ดีกว่า ACS712 (~1.5%) |
| Frequency | 50Hz / 60Hz | |
| Output แบบ | Current output (ไม่ใช่ voltage) | ต้องต่อ **burden resistor** (~10Ω → 0–1V สำหรับ ADC 3.3V/5V) |
| Split type | สามารถเปิด/ปิด jaws ได้ | ไม่ต้องรื้อสายออกจาก terminal |

## การใช้งานกับ ESP32

```
[สาย live ของแอร์ <HOSPITAL>]
        │ (ไม่ตัด — รัด jaws ล้อมสายตัวเดียว)
        ▼
   ┌──────────┐    secondary 0–50mA
   │ SCT-013  │──────┬──────────┐
   └──────────┘      │          │
                burden R        │
                  10Ω          │
                     │          │
                     ▼          │
              0–1V (analog)     │
                     │          │
                     ▼          │
              [ESP32 ADC1_CH0]  │
                     │          │
              DC bias 1.65V ◄───┘ (voltage divider 2× 10kΩ จาก 3.3V)
                     │
                     ▼
              calibrate I_RMS → P = V × I × PF → ∫Wh → kWh
```

### สูตรคำนวณ (firmware ESP32)

```cpp
// V_adc อ่านจาก ADC1 (0–3.3V, 12-bit = 0–4095)
// มี DC bias ~1.65V เพราะ AC สลับขั้ว → ต้อง sample และหา RMS
const float BURDEN_R = 10.0;          // ohm
const float SCT_TURNS = 2000.0;       // SCT-013-000 = 1:2000
const float ADC_VREF = 3.3;
const float GRID_V = 220.0;           // Thailand grid
const float PF = 0.85;                // ค่าประมาณสำหรับแอร์ (inverter สูงกว่า)

float i_rms = computeRMS(samples) * ADC_VREF / BURDEN_R * SCT_TURNS;
float power_w = GRID_V * i_rms * PF;
float wh_increment = power_w * dt_seconds / 3600.0;
```

## เปรียบเทียบกับตัวเลือกอื่น

| Sensor | วัดอะไรได้ | Invasive? | ราคา (บาท) | หมายเหตุ |
|---|---|---|---|---|
| **SCT-013-000** | Current (A) เท่านั้น — ต้องคำนวณ kWh เอง | ❌ Non-invasive (clamp) | ~200 ⚠️ | เหมาะสำหรับงานติดตั้งจริงที่ห้ามตัดสาย |
| [[entities/iot/pzem-004t]] | V/A/W/kWh/PF/Hz ครบ | ✅ Invasive (ต้องต่อ series กับสาย live) | ~350–450 ⚠️ | แม่นยำกว่า แต่ต้องดับไฟต่อสาย — เสี่ยงใน <HOSPITAL> |
| ACS712 | Current (A) — DC หรือ AC | ✅ Semi-invasive (ตัดสายเสียบ terminal) | 90 (verify) | ถูกกว่าแต่ต้องตัดสาย ไม่เหมาะโปรดักชั่น |

**คำแนะนำ**: สำหรับโปรเจ็กต์ <HOSPITAL> ที่ห้ามตัดสายไฟ → **SCT-013 คือทางเลือกเดียวที่ตอบโจทย์ non-invasive และอยู่ในงบ < 1,000 บาท/หน่วย**

## ข้อจำกัด / ข้อควรระวัง

1. **ต้องรัดเฉพาะสาย live ตัวเดียว** — ถ้ารัดสาย live+neutral พร้อมกัน สนามแม่เหล็กจะหักล้างกัน → ค่าเป็น 0
2. **อย่าเสียบสาย live+neutral พร้อมกัน** ผ่าน jaws — เป็นความผิดพลาดที่พบบ่อย
3. **ห้ามเปิดวงจร secondary ตอนที่มีกระแสไหลผ่าน primary** — CT จะผลิต high voltage spike ทำลาย ADC (เสมอต่อ burden resistor ตลอดเวลา)
4. **PF (Power Factor) ประมาณการ**: SCT-013 วัดได้แค่กระแส คำนวณ P = V × I × PF ต้องสมมติ PF (0.85 สำหรับแอร์ non-inverter; ~0.95+ สำหรับ inverter) — ความคลาดเคลื่อน ±10–15% เมื่อเทียบ kWh มิเตอร์จริง
5. **DC bias จำเป็น**: ESP32 ADC รับ 0–3.3V เท่านั้น ต้องยก AC ขึ้นมากึ่งกลาง (1.65V) ด้วย voltage divider 2× 10kΩ
